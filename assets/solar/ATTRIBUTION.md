# Solar System Scope textures

Creator: Solar System Scope / INOVE.
Source: https://www.solarsystemscope.com/textures/
License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

All 12 image files in this folder were downloaded from the source page on 2026-11-01. Original pixels and filenames are unchanged. Used as 3D material maps. The source says the maps use NASA elevation and imagery data, with some enhanced colors and fictional fill for unmapped regions; they are not real-time images.

Orbital reference: NASA NSSDC Planetary Fact Sheet, https://nssdc.gsfc.nasa.gov/planetary/factsheet/ . Periods, eccentricities, inclinations, equatorial diameters and mean distances derive from the metric fact sheet. Display sizes and orbital distances are separately compressed. Initial orbital phases are illustrative; this is not an ephemeris. Moon size/distance and axial spin are illustrative. Illumination is tuned for visual clarity and is not a photometric simulation.

OrbitControls is pinned to Three.js 0.187.0 and distributed under the same MIT license as Three.js. The sole change to that upstream module is replacing its bare three import with the local relative module path.
