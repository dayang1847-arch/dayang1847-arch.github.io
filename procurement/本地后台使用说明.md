# 采购本地后台使用说明

## 启动

Mac 双击“启动采购后台.command”，然后访问 http://127.0.0.1:8923/?view=settings 。服务只监听本机回环地址，关闭终端或按 Ctrl+C 停止，不会自动开机启动。需要 Python 3.10 或更新版本；服务仅使用 Python 标准库，无需安装 npm 或 Python 依赖。也可在目录内运行 `python3 backend/server.py`。

GitHub Pages 无法运行此 Python 后台。在线“系统设置”提供本机部署包和本机入口；密钥只在本机页面填写，在线页面不跨站调用本机服务。请同时保留部署包内的页面、脚本和 backend 目录。

## 邮箱

在邮箱服务商后台开启 IMAP SSL，填写服务器、SSL 端口、邮箱账号和授权码后保存，再测试登录。授权码不一定等于网页登录密码；支持方式取决于邮箱服务商和公司管理员。暂不支持 OAuth 登录，要求 OAuth 的邮箱不能仅靠普通密码连接。

“读取最近 10 封”仅取标题等邮件头信息；点击“查看正文”后才读取正文。使用只读收件箱与 BODY.PEEK，不标记已读，不发送、删除或移动邮件。单封最多读取前 256 KiB，显示正文最多 20,000 字符，不打开附件、外部图片或链接。可导入 .eml 文件在本机解析。

## DeepSeek

API 地址固定为 https://api.deepseek.com ，仅使用官方 `/models` 与 `/chat/completions` 接口。先保存 API Key，读取可用模型，点击模型名称后再次保存。连接测试只读取模型列表，不做文本生成；成功不代表余额、文本生成或具体模型任务已经验证。

分析文本前需勾选确认，只有当前分析框文本会发送至 DeepSeek，可能产生 API 费用。邮件不会自动发送至模型。提取结果仅供人工核对，未知字段保留为空；不会自动定点、外发邮件或提交审批。接口遵循官方文档：https://api-docs.deepseek.com/api/list-models/ 和 https://api-docs.deepseek.com/api/create-chat-completion/ 。

## 保存位置与清除

连接配置保存在当前用户的 `~/.local/share/chaiheng-procurement/connections.json`；目录权限 700，文件权限 600，API 返回只含“是否配置”标记，不返回授权码或 API Key。该文件为本机权限受限的明文文件，不是加密钥匙串，应避免共享此用户目录。

“重置演示”只清除虚构演示记录。要清除真实连接配置，请在对应连接卡片点击“移除配置”。邮件正文和分析结果只保存在当前页面内存，刷新后清空；服务不记录正文、密钥或请求日志。

## 验证范围

自动测试使用隔离临时目录和模拟网络适配器，覆盖密钥不回显、权限、跨站与 CSRF 阻断、静态文件白名单、IMAP 只读与 PEEK、MIME 正文处理、模型发送确认及缺失值保留。真实邮箱、授权码、DeepSeek 余额与模型调用必须填写你自己的有效参数后实测；不能把自动测试通过视为账号已经连接。

## 材料行情

打开 http://127.0.0.1:8923/?view=cost ，点击“更新公开行情”。不需要行情 API Key。监测生意社的铜、铝、PC、PMMA、ABS、PS、PP(拉丝)、LLDPE、PVC 公开参考价，及新浪铜、铝连续期货日线；来源和价格口径分开展示。

每次更新间隔至少 60 秒；来源失败或结构变化保留上次成功值，日期倒退不覆盖；超过 4 个日历日提示过期。缓存位于本机用户目录 `~/.local/share/chaiheng-procurement/market-cache.json`，不含邮箱或密钥。当前按需采集，无后台定时任务。在线网站使用发布快照，需要重新采集与部署才会更新。

导出 CSV 保留来源、日期、单位、采集时间与未知条件。铜现货可在确认口径后带入演示成本情景，期货不自动作为采购价。

## 供应商产品目录

打开 http://127.0.0.1:8923/?view=selection 使用结构化目录。部署包内的 supplier-catalog.json 是产品、参数、来源和待核验事项的完整交换数据。原册关联在浏览器内按指纹校验，不上传 PDF。目录条目未完成工程与认证确认，商务字段保持未知；旧模拟业务单独展示。

## 在线使用自己的 DeepSeek

也可直接打开 GitHub 或 Sites 的“在线采集 · DeepSeek”，在浏览器填写自己的 Key，搜索公开网页、抓取原文、提炼产品/行情资料。无需启动本机服务；Key仅在当前页面内存，刷新后重新填写。确认的产品候选保存在该网站的当前浏览器，未自动上传到服务器。该模式与上述本机保存的邮箱/DeepSeek配置独立。本机页面同样可以使用在线采集。

# 产品图片

物料选型库可单条“查看产品图片”，或开启“显示全部图片”后随滚动加载，支持放大和来源页码。默认不下载图片。部署时保留 `catalog-images.json` 与 `catalog-images/` 文件夹；图片缺失不影响文字参数。多型号组图有明确标记，不作为单一型号结构确认。



## 参数展示设置（2026-10-22）

物料选型库的“参数展示设置”，以及系统设置中的“物料参数展示管理”，可勾选目录字段、修改显示名称、上下排序，或按行添加预留名称。默认显示13类参数，已有160类目录字段可供选择；空白表示资料未提供，不代表0或不适用。各标准的额定值分别保留。

保存只影响当前浏览器的卡片展示，不改原始产品记录。取消不应用草稿；恢复默认后还需保存。可导出/导入展示配置JSON，在其他浏览器共享，导入后须保存生效。浏览器禁止存储时会提示未保存。

点击卡片“全部参数与出处”查看原始技术参数与逐项来源，再展开“全部字段”查看含空白项的完整参数名称表。自定义名称不会自动生成技术值；未匹配目录字段的名称保持空白，需后续依据资料补齐。配置和自采候选不会自动同步到公共网站或其他人的浏览器。

用户自行定义参数名称；取消卡片勾选或移除显示，不删除完整字段表中的自定义名称。恢复默认会清除自定义展示配置，保存后生效；需要保留时先导出配置。


## 用户上传供应商图册（2026-10-22）

入口：物料选型库的“上传供应商图册”或左侧同名菜单。仅在当前浏览器的 IndexedDB 保存原PDF、解析进度和审核候选；网站服务器、GitHub和其他用户不会收到原册。清除网站数据会丢失这些记录，请保留原PDF并定期导出任务JSON备份。

1. 选择PDF（最大50MB、1000页；本浏览器累计200MB）。首次选择只在浏览器读取，不会自动调用模型。重复文件按SHA-256恢复任务。
2. 配置自己的DeepSeek Key并读取账号模型，返回图册页面。Key只在页面内存，刷新即清除。图文模式需支持图像的模型，例如官方文档中的deepseek-flash；仅原生文字模式可用文字模型，扫描页文字不足会明确失败。
3. 输入实际PDF页码（如1-10,15），单次最多50页，默认前10页。勾选所选页发送及账号计费确认，点击开始。图文模式逐页发送原生文字与1幅整页图；密集表格选项额外发送4幅分区图，增加用量。不会把PDF原文件作为公开附件上传。
4. 可暂停并分批继续；成功页跳过，失败页只在手动开始后重试。401/402/429停止队列，无付费自动重试。单页输出不完整不会保存半截产品；达到20条产品上限会提示核对是否漏项。封面、空页和失败页不会编造产品。
5. 对照PDF原页核对型号、标准、单位及参数，勾选产品和审核确认后入库。扫描件转录和字段由同一模型生成，始终标记AI图检待核验，不作为独立原文验证。缺少引文或数值不受支持的参数清空。
6. 入库后可在选型库按供应商、型号及参数搜索、比较和自定义展示。同图册同页同型号再次入库更新候选，不重复叠加；不同页的同名型号分别保留待人工核对。原页按钮是整页预览，不能当成单型号照片。商务信息、工程批准和供应商准入保持未知。
7. 导出任务与候选JSON不含PDF或Key。恢复时先上传同一原册，再选择对应JSON，指纹和页数不一致会拒绝。此功能不自动将个人图册候选发布为公共目录。

PDF.js 6.4.299的引擎、worker、CMaps、字体及WASM均随本地服务包发布，来源与SHA-256记录在 vendor/pdfjs/manifest.json，保留上游许可证。在线版和本地HTTP服务支持PDF上传；单文件离线HTML不加载独立PDF模块，应使用本地服务包。正式AI解析需要自己的有效Key、账号权限和余额；演示测试不代表付费接口已连通。

统一参数标准：打开物料选型库的“统一参数检索”，添加标准字段并应用条件。默认164类标准，空缺不补0。打开“统一参数标准管理”可编辑别名、类型、单位和新增字段；保存只作用于当前浏览器，可通过标准JSON导出/导入共享。参数展示设置控制卡片可见字段，与标准定义分开。PDF和在线采集候选入库后按同一标准映射；单位不明的原值显示待核，不参与数值检索。完整标准字段、空白项、原参数和出处均可导出。


页面归并：侧栏现有采购总览、物料与供应商、数据导入、采购协同、成本与行情、系统设置六项。物料与供应商内切换选型/档案/参数；数据导入内切换PDF/网页并共用在线DeepSeek连接；采购协同内切换需求/报价/任务。在线连接和本机保存的报价分析连接用途与保存边界不同，后者仍在系统设置中单独配置。旧页面链接兼容，不清空图册、候选、字段或业务数据。


## DeepSeek行情一键刷新（2026-10-22）

进入“成本与行情”，展开DeepSeek连接，用自己的Key读取模型；确认查询与计费说明，选择现货/期货/全部后点击“DeepSeek一键刷新”。此连接为页面内存连接，与PDF/网页导入共用；本机持久化报价分析Key不会自动交给浏览器。刷新结果仅存当前浏览器，标为AI提炼待核对，保留原文及日期，失败保留旧值。每次启动间隔60秒，可取消、导出备份及切回发布快照。详细来源约束和调用上限见README。需自己的有效Key、权限与余额；未实测真实付费调用。原有本机“更新公开行情”仍可单独使用。
