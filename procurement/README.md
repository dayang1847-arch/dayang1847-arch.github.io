# 采衡采购协同工作台

采购业务交互 Demo，业务演示中的供应商、物料、项目、报价与证书为虚构数据；物料选型库另有真实供应商产品目录提取结果；“成本与行情”已接入公开市场参考价及期货日线。演示页面展示采购总览、物料选型、需求聚合、成本情景、询报价、供应商管理和任务结果回填。

打开页面右上角的“演示指南”，按五步完成选型、报价比较、需求归并、成本测算与议价回填。演示为中文界面，记录只保存在当前浏览器，支持重置与 CSV 导出。

连接设置提供需自行配置与实测的本机 IMAP 只读邮箱和 DeepSeek API 后台；OA、ERP、企业微信及工商接口未接入；行情按需采集，未实现交易所逐笔实时行情或无人值守定时更新。报价导入支持 `sample-quotes.csv` 所示的标准 CSV；关键词匹配不等于完整语义理解。模拟研发确认不代表真实技术批准，目标收益不等于已实现降本。

页面为原生 HTML、CSS、JavaScript，演示页面无构建步骤和预置密钥；可选本机 Python 后台用于邮箱、DeepSeek 与公开行情采集。根站点由 GitHub Pages 发布，页面内可返回 DC Web 作品集。

## 本机连接后台

在线连接设置可下载 `local-service.zip`，Mac 双击“启动采购后台.command”，打开 http://127.0.0.1:8923/?view=settings 。授权码和 API Key 只保存在本机用户目录，不返回到前端或写入 GitHub。支持 IMAP 只读邮件、EML 导入和经确认的 DeepSeek 文本提取；无 SMTP 外发、自动采购或自动审批。详见“本地后台使用说明.md”。

## 真实材料行情

“成本与行情”监测铜、铝、PC、PMMA、ABS、PS、PP(拉丝)、LLDPE、PVC 的公开现货参考价，以及铜、铝连续合约日线收盘价。来源为生意社公开日榜与新浪财经期货接口；两种价格口径分开展示。每条保留来源网址、来源日期、采集时间、上期值；未知牌号、地区、税费、运费不补齐。现货图只有两期公开值，期货展示最近 60 个交易日，无插值。

在线页读取发布时 `market-data.json` 快照，不会自动持续更新。打开本机后台的 http://127.0.0.1:8923/?view=cost 可点击“更新公开行情”，每次间隔至少 60 秒；本机缓存存入用户数据目录 `market-cache.json`。采集失败保留上次成功值并提示，来源日期超过 4 个日历日提示过期，来源日期倒退不覆盖。缺失与失败不会被写成零。

可在本目录运行 `python3 backend/market.py` 更新待发布快照，再按正常网站部署流程发布。没有预置账号、付费报告接口或定时任务；不绕过付费内容。接口可能变化，公开可读不等于上游数据的任意商业转载授权。

点击铜现货行的“带入铜价情景”，核对来源后确认，只更新模型里的铜价，并保留取价依据；用量、重量和基准仍是演示参数。期货、塑料价不会自动套入铜线模型；改动铜价后自动清除原取价标记。

验证：本机真实采集 4 个来源、11 条记录成功；自动测试覆盖来源日期/单位校验、缺失/非有限数字、期货与现货分离、失败保留、日期倒退及过期提示。

## 供应商产品结构化数据库（2026-10-22）

物料选型库默认展示 5 家供应商（江苏长河、广东欧骏、厦门福朗、江西高超及厦门广泓 GHGM）的 1,023 条产品/系列/附件、11,322 条参数，覆盖 5 份目录全部 162 页。749 条明确订货代码属于系列下的变体，不与产品数相加宣称 SKU。保留同码不同结构、原册冲突及待核验项；不同标准和使用分组的额定值分行保存。

支持型号/订货代码/参数关键词搜索、供应商/类别/间距/标准筛选、最多 4 项候选对照、完整参数与原文来源、CSV 和 JSON 导出。通过“关联本机原册”按 SHA-256 匹配 PDF，在浏览器生成对应页链接；文件不会上传。“数据覆盖与待补齐”展示逐页覆盖。旧虚构流程在“业务演示样例”标签中保留。

所有条目为 catalog_extracted_unverified，尚非企业已批准料号。图纸尺寸方向、孔位、公差、认证有效性、实际使用条件仍需核验；目录本身的疑似错误保留原文，不擅自修改。价格、币种、税率、运费、MOQ、交期、库存、付款和供应商准入均未知，保留 null。整理日期不代表目录或报价最新日期。
