## 2026-10-22 智能核价更新

进入 成本模型与行情监控 → 注塑成本 → 智能核价 / 报价复核，或使用在线入口的 `tool=smart` 参数。新增三个业务入口，共用真实机台报价、粒子价格和已核对历史案例：

1. **报价反向复核**：本地读取报价，自己的DeepSeek提炼带引文草稿；核对数量、单位、含料范围、税费、计费和有效期后，与本次模型区间比较。资料不全时只列缺口，不判“合理/不合理”。
2. **参数核价**：净重、完整周期、穴数、数量、良率、换模时间，加上所选机台/粒子记录，确定性计算原料、加工、其它费用、成本加成及批量金额。其它费用与加成大于0时填写依据。原料按整数射出次数核算，包含报废与尾数消耗；流道按每模输入，回用比例单列。
3. **STEP方案**：12MB以内STEP/STP在浏览器本地Worker读取，单位统一mm；装配需明确选择实体。闭合且方向一致的网格才给估算体积，密度确认后可推算重量。包络面积、压力范围和安全系数用于锁模吨位初筛，1/2/4/8穴比较月产能及所选费率下的成本，可带入继续核价。未核对注射量、拉杆间距、模厚、开模行程、冷却、倒扣、壁厚和模具投资，不能证明机台适配或经济最优。实际零件仍须工艺/模具工程师核实与试模。

**粒子价格 / 历史案例库**：记录材料种类、牌号、生产商、供应商、改性/玻纤/阻燃/颜色、密度、CNY/kg价格区间、税运、日期、有效期、来源和人工核对依据。公开现货元/吨可换算为元/kg参考草稿；不自动认定指定牌号价格。未录入时保持空白。历史图纸/报价可逐件提炼、核对后保存工艺案例，按材料与相似特征检索最多5条作为本次AI上下文，不是模型训练或已验证当前零件。AI/网格估计不能直接存实测案例；以实际生产记录复核替换后，须注明依据。

**资料与AI**：支持5份以内XLSX、文字PDF、UTF-8 TXT/CSV、PNG/JPEG，文字合计60,000字符；PDF每批最多5页，扫描PDF先OCR。图片每次1张，浏览器缩放压缩；PNG/JPEG及STEP线框预览使用账号可用的官方 `deepseek-flash` 图片模型（或官方兼容别名）。先本地预览，明确同意后才向自己的DeepSeek发送所选原文/图片、机台、粒子、匹配案例与几何摘要。STEP原文件不发送；AI不补造商业价格或自动入库。模型截断、错误、取消或清Key后不采用迟到结果，也不自动重试付费请求。未用用户Key验证真实付费调用。

**本地与在线边界**：在线版不预置私人机台费；导入本机实际报价JSON或已核对模板。私人资料、价格、案例只在当前浏览器，JSON导出/恢复与撤销可用，不随部署同步。Key仅页面内存。独立模具分摊、运费等仅在明确填入其它每件费用及依据时计入，税额不自动换算。双击单HTML仍可参数核价和资料管理；STEP的Worker/WASM需在线版或本地HTTP后台。`local-service.zip`已打包解析器，无须外部CDN。原始采购资料和私人价格不在公开包。

技术依据：[DeepSeek图片](https://api-docs.deepseek.com/guides/vision/)、[JSON输出](https://api-docs.deepseek.com/guides/json_mode/)、[occt-import-js](https://github.com/kovacsv/occt-import-js)、[Autodesk锁模力](https://help.autodesk.com/cloudhelp/2014/ENU/MoldflowAdvisor/files/GUID-73BF9FA2-9CBE-46F4-B324-58FB7EB6E853.htm)。依赖版本、完整性、许可证和可替换源码见 `vendor/occt/`。

## 统一参数标准与检索（2026-10-22）

`standard-parameters.json` 是所有供应商共用的第一版164类标准字典：稳定标识、名称、分组、数值/文本类型、标准单位、名称别名、来源key别名，以及额定值的标准/条件范围标识。发布版标准对全部供应商通用。没有资料的标准字段为`null`，不补0，不根据别的系列推定。原始`specifications`和逐项证据保持不变；每个非空标准值保留`source_index`、页码、原标准/条件、归一状态。字段含义冲突保留待映射，原生key与归一中文名一致时不会被宽泛的来源原名覆盖。

物料选型库顶部“统一参数检索”支持最多8条AND条件：数值等于/不小于/不大于/覆盖数值或范围，文本包含/相同，以及资料已提供/未提供。编辑后点击应用；无效输入不覆盖已生效条件；清空参数条件或清除筛选会移除约束。示例“间距=5.08mm，额定电流≥16A”在当前公开目录匹配4条记录。数值大于或小于比较采用范围的保守端点，离散值不推断为连续范围。单位明确且兼容时换算；无单位、单位冲突或无法确定的格式仍显示原值，但排除数值比较。AWG不擅自换算mm²；VAC/VDC保留属性。两个以上额定参数要求同一明确原标准及使用条件，不把IEC电压与UL电流拼接。

“统一参数标准管理”可编辑名称、分组、类型、单位、别名、来源key及定义，或新增字段。稳定ID不可改；重复名称/别名或key指向冲突会拒绝保存。保存为当前浏览器草案，清空参数筛选并从原始规格重建所有供应商的标准索引。取消不应用；存储失败保留旧标准。导出/导入标准JSON可在其他用户浏览器共享，导入后仍需保存；这不是自动多人同步。新增字段可先为空，后续导入遇到明确字段或别名时再填值。卡片“参数展示设置”独立控制哪些标准字段显示，不会修改标准定义。

完整详情保留原始参数和含空白项的统一标准表。并排比较按统一字段、原标准、条件、单位分行。筛选CSV包含全部标准列和空白项，JSON数据库包含当前标准字典、每条记录的`standard_parameters`、未映射项和原参数。PDF及网页DeepSeek提炼接收当前字典，核对入库后由同一映射器生成搜索索引；模型输出仍需证据及人工核验，既有个人资料在标准修改后也从原规格重新映射。
