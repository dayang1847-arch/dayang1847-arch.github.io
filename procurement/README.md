# 采衡采购协同工作台

## 从供应商档案上传目录并结构化（2026-10-22）

入口：“物料与供应商 → 供应商档案”（`?view=library&tab=suppliers`）。6家实际企业卡片与档案均提供“上传目录 · DeepSeek结构化”，原“产品待结构化”的合达也可直接使用。顶部通用上传可先选择企业，也可暂不关联，按原文建立独立候选供应商。继续复用数据导入的PDF页面，不增设重复页面。

1. 从目标供应商点击上传，自动带入当前企业；PDF最大50MB、1000页。首次选择仅存本浏览器，不发送或调用AI。
2. 展开共享DeepSeek连接，读取自己账号的模型；选择页码、文字/图文方式，确认发送后开始。按已有164类标准字典提炼，缺失字段为空，原标准、条件、引文和PDF页码保留。
3. 对照原页逐条核对后勾选入库。保留模型识别的原供应商名称；若与所选企业不一致，显示主体冲突，须额外确认归属或取消该产品。多公司共用目录不能自动按品牌合并主体。关联为用户声明，不代表工商、认证或准入核验。
4. 入库后可从供应商卡片查看该企业的全部选型产品；本浏览器候选数量单独显示，公开目录统计不改写。合达原公开目录仍待提取，自己的新增候选可先用于检索、比较及标准字段展示。原AI名称和用户关联依据保存在候选JSON与核对说明中。
5. 重复文件按指纹恢复进度，不自动改变既有归属；已有入库候选的任务锁定关联。首次入库前可修改关联。备份在其他浏览器恢复时，须先上传同一原册并选择同一企业；不同企业的备份不会改写归属。未关联的旧候选保留独立身份，不按同名自动合并。

原PDF、图册任务与入库候选保存在当前域名IndexedDB，刷新后保留；不同设备和域名不自动同步。公共网站、GitHub与其他用户不会收到原册。确认后所选页直接发送到用户的DeepSeek账号；Key仍仅在页面内存。可从图册任务导出备份，备份不含PDF或Key。存储失败不报告入库成功，失败、暂停与账号错误沿用原逐页处理机制。

验证：81项Node及15项Python检查，共96项通过。另用明确标识的合成PDF与测试备份检查真实文件上传、关联预填、冲突确认、候选入库、刷新保留及供应商筛选；桌面与390px手机布局检查。未使用真实Key进行付费AI解析，测试备份不代表真实模型调用。


## 在线行情一键刷新（2026-10-22）

进入“成本与行情”（`?view=cost`），展开DeepSeek连接，用自己的Key读取模型；勾选查询、提炼与账号计费说明，然后点击“DeepSeek一键刷新”。页面默认刷新9项现货参考；切换期货可刷新2项连续合约收盘，全部品种共11项。总览亦有入口。与PDF及网页导入共用同一内存Key，刷新页面后重新填写。

先用官方Fetch读取已配置的生意社/新浪原文，再由所选模型提炼。当前页无可用记录时最多搜索一次同提供商替代页并读取；现货只接受生意社大宗日榜，厂商报价不混入通用指数。每来源组最多2次读取、1次搜索、2次提炼；现货最多2组，全部最多4组。搜索/读取/模型可能分别计费，两个启动至少间隔60秒；无定时自动调用或相同请求自动重试。401/402/429停止整批；取消或清Key不采用晚到结果。

每项检查原文引文、同一行材料与价格、币种、吨价单位和价格日期；期货须有连续合约与收盘依据。来源超过4个日历日、比已有数据更旧、同日不同价或变动超过50%时保留旧值。多单位表仅核对目标材料行，未换汇或换算。仍标记“AI提炼待核对”，文本匹配不保证日期列语义完全正确，使用前应查看引文与原站。未知牌号、地区、含税和运费保持null，不把AI提炼当作实际采购报价。

符合检查的新日期记录保存在当前域名的localStorage（`procurement-market-ai-v1`），显示来源网址、原文引文、来源摘要SHA-256、截取状态和尝试时间；发布快照不改写。可切回发布快照、恢复个人参考、导出AI JSON及含来源CSV。没有新日期会显示来源未更新，不能把检查时间冒充价格日期；失败保留已有值并逐项提示。新发布快照同日或更新时优先。浏览器清理会丢失个人参考，需导出备份；不同设备或域名不自动同步。

通过人工核对后可将铜现货带入演示成本情景，期货及塑料不套入铜线模型。此刷新与网页采集的“行情草稿导出”是不同用途：前者更新个人行情视图，后者仍为可导出研究草稿。未在GitHub中预置Key。验证：73项Node及15项Python检查共88项通过，覆盖失败保留、取消、存储失败、过期、口径冲突、限流和凭据清除。真实Key的付费搜索、读取与生成尚未测试。

## 在线 DeepSeek 自带 Key（2026-10-22）

在线入口：`?view=research`。GitHub Pages 与 Sites 均可直接使用，不需要先运行本机后台。数据导入统一提供PDF与网页入口。

1. 填写自己的 Key，读取账号模型列表并选择模型；此测试不代表搜索/生成权限或余额已经验证。
2. 确认查询和资料可发送到 DeepSeek，输入关键词及可选域名范围搜索，或提供一个公开页面网址。

4. 选择产品参数或行情类型，确认后调用模型生成 JSON。每个产品和参数保留短引文；无法定位的记录被排除，缺少证据或原文数值不对应的参数清空为 null。所有结果仍需人工核对。
5. 产品逐项勾选并确认后，加入当前浏览器的选型候选库，可检索、对照、导出备份、清除及在页面关闭前撤销清除。行情草稿可导出，不自动覆盖公开行情看板。

在线调用依赖官方网络、账号余额及权限；搜索/抓取/生成可能产生费用，不自动重试付费请求。目标站不可用、登录/付费限制、无正文、限流、错误和取消均会明确提示，不伪造成功。每页提炼最多发送前20,000字符，总共最多3份，单次最多20条记录；截取会在来源卡提示。未知报价条件和供应商准入保持未知，人工确认候选不代表工程批准。

物料选型库的“参数展示设置”，以及物料与供应商 → 参数管理 → 卡片展示，可勾选目录字段、修改显示名称、上下排序，或按行添加预留名称。默认显示13类参数，现有164类统一标准字段可供选择；空白表示资料未提供，不代表0或不适用。各标准的额定值分别保留。

保存只影响当前浏览器的卡片展示，不改原始产品记录。取消不应用草稿；恢复默认后还需保存。可导出/导入展示配置JSON，在其他浏览器共享，导入后须保存生效。浏览器禁止存储时会提示未保存。

点击卡片“全部参数与出处”查看原始技术参数与逐项来源，再展开“全部字段”查看含空白项的完整参数名称表。自定义名称不会自动生成技术值；未匹配目录字段的名称保持空白，需后续依据资料补齐。配置和自采候选不会自动同步到公共网站或其他人的浏览器。

用户自行定义参数名称；取消卡片勾选或移除显示，不删除完整字段表中的自定义名称。恢复默认会清除自定义展示配置，保存后生效；需要保留时先导出配置。


## 用户上传供应商图册（2026-10-22）

入口：物料选型库的“上传供应商图册”或数据导入 → PDF图册。仅在当前浏览器的 IndexedDB 保存原PDF、解析进度和审核候选；网站服务器、GitHub和其他用户不会收到原册。清除网站数据会丢失这些记录，请保留原PDF并定期导出任务JSON备份。

1. 选择PDF（最大50MB、1000页；本浏览器累计200MB）。首次选择只在浏览器读取，不会自动调用模型。重复文件按SHA-256恢复任务。
2. 配置自己的DeepSeek Key并读取账号模型，返回图册页面。Key只在页面内存，刷新即清除。图文模式需支持图像的模型，例如官方文档中的deepseek-flash；仅原生文字模式可用文字模型，扫描页文字不足会明确失败。
3. 输入实际PDF页码（如1-10,15），单次最多50页，默认前10页。勾选所选页发送及账号计费确认，点击开始。图文模式逐页发送原生文字与1幅整页图；密集表格选项额外发送4幅分区图，增加用量。不会把PDF原文件作为公开附件上传。
4. 可暂停并分批继续；成功页跳过，失败页只在手动开始后重试。401/402/429停止队列，无付费自动重试。单页输出不完整不会保存半截产品；达到20条产品上限会提示核对是否漏项。封面、空页和失败页不会编造产品。
5. 对照PDF原页核对型号、标准、单位及参数，勾选产品和审核确认后入库。扫描件转录和字段由同一模型生成，始终标记AI图检待核验，不作为独立原文验证。缺少引文或数值不受支持的参数清空。
6. 入库后可在选型库按供应商、型号及参数搜索、比较和自定义展示。同图册同页同型号再次入库更新候选，不重复叠加；不同页的同名型号分别保留待人工核对。原页按钮是整页预览，不能当成单型号照片。商务信息、工程批准和供应商准入保持未知。
7. 导出任务与候选JSON不含PDF或Key。恢复时先上传同一原册，再选择对应JSON，指纹和页数不一致会拒绝。此功能不自动将个人图册候选发布为公共目录。

PDF.js 6.4.299的引擎、worker、CMaps、字体及WASM均随本地服务包发布，来源与SHA-256记录在 vendor/pdfjs/manifest.json，保留上游许可证。在线版和本地HTTP服务支持PDF上传；单文件离线HTML不加载独立PDF模块，应使用本地服务包。正式AI解析需要自己的有效Key、账号权限和余额；演示测试不代表付费接口已连通。

## 统一参数标准与检索（2026-10-22）

`standard-parameters.json` 是所有供应商共用的第一版164类标准字典：稳定标识、名称、分组、数值/文本类型、标准单位、名称别名、来源key别名，以及额定值的标准/条件范围标识。发布版标准对全部供应商通用。没有资料的标准字段为`null`，不补0，不根据别的系列推定。原始`specifications`和逐项证据保持不变；每个非空标准值保留`source_index`、页码、原标准/条件、归一状态。字段含义冲突保留待映射，原生key与归一中文名一致时不会被宽泛的来源原名覆盖。

物料选型库顶部“统一参数检索”支持最多8条AND条件：数值等于/不小于/不大于/覆盖数值或范围，文本包含/相同，以及资料已提供/未提供。编辑后点击应用；无效输入不覆盖已生效条件；清空参数条件或清除筛选会移除约束。示例“间距=5.08mm，额定电流≥16A”在当前公开目录匹配4条记录。数值大于或小于比较采用范围的保守端点，离散值不推断为连续范围。单位明确且兼容时换算；无单位、单位冲突或无法确定的格式仍显示原值，但排除数值比较。AWG不擅自换算mm²；VAC/VDC保留属性。两个以上额定参数要求同一明确原标准及使用条件，不把IEC电压与UL电流拼接。

“统一参数标准管理”可编辑名称、分组、类型、单位、别名、来源key及定义，或新增字段。稳定ID不可改；重复名称/别名或key指向冲突会拒绝保存。保存为当前浏览器草案，清空参数筛选并从原始规格重建所有供应商的标准索引。取消不应用；存储失败保留旧标准。导出/导入标准JSON可在其他用户浏览器共享，导入后仍需保存；这不是自动多人同步。新增字段可先为空，后续导入遇到明确字段或别名时再填值。卡片“参数展示设置”独立控制哪些标准字段显示，不会修改标准定义。

完整详情保留原始参数和含空白项的统一标准表。并排比较按统一字段、原标准、条件、单位分行。筛选CSV包含全部标准列和空白项，JSON数据库包含当前标准字典、每条记录的`standard_parameters`、未映射项和原参数。PDF及网页DeepSeek提炼接收当前字典，核对入库后由同一映射器生成搜索索引；模型输出仍需证据及人工核验，既有个人资料在标准修改后也从原规格重新映射。

验证：12项标准/空值/单位/标准条件/配置/搜索/导入/提示词回归测试，加上既有54项前后端测试，共66项通过。桌面与390px手机界面检查包括组合条件、缺失项检索、清除、标准编辑取消/保存/重载和原始参数保留。未使用真实Key进行付费调用。
