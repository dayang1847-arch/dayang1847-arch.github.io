# 越语冒险

手机优先的静态网页课程：14 个单元、42 课、420 道互动题及 96 个日常高频词，覆盖越南语基础、日常交流与照明行业销售及供应链沟通。

## 运行

线上学习地址：https://dayang1847-arch.github.io/vietnamese-learning/ 。个人主页 DC Web 已添加“越语冒险”项目入口。网站由 `dayang1847-arch/dayang1847-arch.github.io` 仓库的 `main` 分支发布，网页课程放在 `vietnamese-learning/` 子目录。

在本目录执行 `npm start`，然后访问 <http://localhost:4173>。无需安装依赖。执行 `npm test` 验证课程结构与闯关逻辑。

## Android 手机版

**直接安装 APK：**将 `dist/越语冒险-Android.apk` 发送到 Android 手机并点开安装。14 个单元、42 课、题目、词汇、音标、词源说明、脚本和图标均内置在安装包中，阅读与答题无需连接电脑或同一 Wi-Fi。Android 8.0 及以上可安装。若手机提示“允许安装未知应用”，在手机系统中允许当前文件管理器安装即可。此包由本地测试证书签名，适合个人侧载；不用于应用商店发布。学习记录保存在该 APK 的应用数据中，与 Chrome/PWA 版互不共享。真人录音“Việt Nam”仍需联网播放；其余发音使用手机系统的越南语声音。手机没有可用越南语声音时，听力题会按原规则跳过。

如需完整重新构建 APK，运行 `android-app/build-apk.sh`；它使用 Android SDK 35 的 `aapt2`、`d8`、`zipalign`、`apksigner` 和 JDK 17。若 SDK 暂时不可用、但仍保留上次的 `android-app/.build/aligned.apk`，可运行 `python3 android-app/repack-apk.py` 只更新网页课程资源和版本号。该备用构建沿用原生容器，不能更新 Java 代码。保留 `android-app/.signing/debug.keystore`，后续安装更新版才能覆盖已安装应用。

项目已封装为可安装的 PWA，包含主屏幕图标、独立窗口和离线课程缓存。正式安装时，先把本目录的静态文件部署到任意 **HTTPS** 网站，再用 Android Chrome 打开该地址，点页面上的“安装到手机”，或在 Chrome 菜单中选“安装应用／添加到主屏幕”。首次在线打开后，课程文件会缓存在手机中；设备语音合成与词源外部链接仍取决于手机系统和网络。

只想在同一 Wi-Fi 下立即用手机预览：运行 `./start-mobile.sh`，按终端显示的 `http://局域网IP:4173/` 在手机 Chrome 打开。这个 HTTP 地址可浏览学习，但 Android 在非 HTTPS 局域网地址上可能只创建快捷方式，无法获得完整离线安装。手机上的学习记录属于该地址和浏览器；换成正式 HTTPS 地址后不会自动同步。

## 内容维护

- `course.js` 是课程修订入口。每课含讲解与五条越中词句，系统据此生成 10 道题。修改已发布课程后递增 `COURSE_VERSION`，并保持已有课时及题目 ID 稳定，以免影响本机学习记录。
- `vocabulary.js` 维护常用词汇，词汇页支持分类、搜索和播放发音。
- `explanations.js` 维护逐词释义、句子逻辑和固定说法说明；课程预习页展开后，每个词都有独立的越南语发音按钮。
- 在“本课词句 → 单词逻辑解释”或发音记录中点击“发音与词源”，可进入音节详情页，查看当前语境下的汉越词判断、相关汉字、词义演变、记忆线索、例句与发音。`word-history.js` 是词源修订入口；有来源核实的词才显示词源结论，其他词明确标为“词源待核”。同形音节可能有不同来源，新增词条时应按具体义项核对并附来源链接。
- 音节详情页还解释越南语字母组合的发音逻辑，尤其是北部 `gi` 的 /z/、`g/gh` 的 /ɣ/，并提供对比听音。规则与来源在 `spelling-rules.js` 维护；这是拼写与口音说明，不等于每个词的词源判断。
- “发音训练”可按 42 课查看全部 210 条课程词句，也可按分类查看 96 个日常词条；支持全库中越文搜索、整句与逐音节播放。`ipa-data.js` 为 363 个越南语音节提供北部口音参考转写，使用 James P. Kirby 的 [vPhon 2.1.1](https://github.com/kirbyj/vPhon) 生成，采用 IPA 字符与上标 Chao 声调数值。`LED`、`email`、`lumen`、`taxi`、`watt` 属外来写法，未强行生成越南语 IPA；可依设备语音听音。课程或词汇新增音节时须同步更新该文件并核对转写。
- 真人音频登记在 `course.js` 的 `AUDIO` 中。每条应包含文件地址、来源页、作者、许可、口音及是否修改。当前使用一条已核实北部口音的 Wikimedia Commons 录音，其他词句提供内置合成音频，设备语音仅作为备用。网络加载或播放权限失败时提示重试，不会自动跳过听力题。
- 页面中的“音频与内容说明”显示授权信息。正式增补录音前应逐条核对来源页和许可。
- 用户进度只存在浏览器 `localStorage`；不含账号和跨设备同步。

## 语言逻辑与封面更新

课程与 96 个词条的详解现在区分完整词块和书写音节，提供句型、语境、逐音节发音与来源入口。排序题按词块排列；固定表达只有一个词块时改为词义题。问句优先判断句末标记，避免把“đã…chưa”问句解释成已完成陈述。“gì”按共享 i 的 gi 拼写分析。语言逻辑页有 8 个对比练习；它是课程内学习提示，不是通用语法分析器。未核实词源继续保留待核标记。

封面采用内置 ImageGen 编辑生成的成年男性探险插画，网站使用 assets/cover-v2.jpg，原图为 cover-v2.png。详细提示词见 assets/cover-v2-prompt.txt。PWA 缓存包含语言逻辑模块与封面。新版 Android 源码支持 JPEG；更新安装包需重新运行完整构建，不能沿用只支持旧资源的 Android 壳。

## 2026-10-14 发音修复

网页包含课程、词块、音节、声调和发音规则示例的内置合成音频，不再以系统是否安装越南语声音作为按钮可用的前提。合成音频来源、作者、许可、逐条定位和文件校验记录见 audio/SOURCES.md 与 audio/manifest.json。首次缓存完成后可以离线播放。

播放器在用户点按时开启声音通道，复用少量已解码音频包以限制手机内存。切页或重复点击会取消旧播放；网络失败可重试，浏览器拦截会提示再次点按。听力题只有播放开始后才能提交；网络和权限失败不会被悄悄当作已听或错误答案。

iPhone 建议用 Safari 打开后点按扬声器，并调高媒体音量。支持 AudioSession 的 Safari 使用 `playback` 通道，避免网页发音跟随铃声静音开关；旧版 iOS 若仍无声，请关闭静音模式。此接口按能力检测使用，不支持时继续正常播放。

Android 完整构建及网页内容包已包含音频目录，旧安装包需重新构建后才会获得此更新。
