# DC Web

Dayang.Cao’s public portfolio and selected browser runtime files.

Full project source, server code, development files and Git history are maintained separately in a private repository. This repository starts with a new history and contains only explicitly selected presentation files.

Preview: `python3 -m http.server 4173 --bind 127.0.0.1`.

The PDF-to-CAD application remains available with its corresponding source, build files and license notices in `pdf-to-cad/`. Its AGPL/GPL and other third-party terms are preserved.

The homepage includes a locally hosted Three.js starfield with pause, reduced-motion and static fallback support. Browser runtime and the Three.js MIT license are included; no external CDN or build is required to browse the site.
