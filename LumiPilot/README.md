# LumiPilot 密码分享入口

GitHub Pages 仅保留入口，自动进入独立服务端登录；登录后展示当前情报操作台。

在本机 LumiPilot 的“资料与设置 → 账户与设置 → 线上账号设计台”维护用户名、密码及启停状态，保存后自动同步到认证服务，无需重新发布 GitHub 页面。

密码与派生值不提交到 GitHub。已公开的历史提交仍然公开；设置密码不能追溯撤回历史资料。线上分享保持只读，实时采集与 AI 需要完整 Python 后台。
