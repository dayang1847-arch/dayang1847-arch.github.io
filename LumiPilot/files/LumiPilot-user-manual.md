# LumiPilot 使用说明

版本：1-e74461cbeb93 · 更新：2026-10-13T05:51:32+00:00

本说明由本机维护清单生成，与当前软件实现文件的版本关联。

## 开始使用

本机应用直接使用；线上版通过邮箱验证与管理员审批进入共享工作台，再按项目推进照明研发。

软件入口：`#projects`

1. **打开工作台**：双击桌面的 LumiPilot.app，等待浏览器打开 [本机服务地址未公开] 线上版访问管理员提供的 HTTPS 地址，验证邮箱并获批后进入同一工作台；账号操作详见“邮箱登录与访问管理”。
2. **选择研发对象**：在“项目数据库”找到本机研发方案并点击“进入项目”，或点击“新建项目”填写名称、备注、国家、产品品类及目标性能和批量。项目行的“管理”可编辑、重命名或移至回收站；历史档案与目录线索先用于查阅，再按需要建立新研发方案。
3. **补充依据与输入**：在“市场与来源”筛选竞品并“加入参考”；在“照明知识库”上传对应国家、产品和版本的资料。再进入“产品方案”保存规格、生成草案，并按需要导入配光、光谱或工程 BOM。
4. **确认保存与下一步**：按各页面的保存按钮提交输入或结果，回到“当前项目工作台”检查待办。资料或规格发生变化后，重新生成方案；导出研发摘要与依据附件供团队复核。

可获得的结果：

- 按项目保存的产品定义、参考依据与分析记录
- 可下载的研发摘要、依据附件及各模块结果

使用注意：

- 当前是照明 OEM/ODM 研发原型；状态标签说明资料是否保存，不代表样机性能、量产批准或认证通过。
- 本机项目和原件保存在当前电脑；线上版统一保存在部署服务器，获批成员共享项目与资料。公开采集、物料查询、行情及路线更新需要联网。
- 打不开时先重新双击应用，再刷新本机地址。端口冲突或启动提示需按提示排查，不另外建立一套资料库。

## 项目数据库

集中新增、编辑、重命名和整理已知项目，删除后可从回收站恢复；原始档案与当前研发目标分别保存。

软件入口：`#projects`

1. **新增研发项目**：点击“新建项目”，填写名称、可选备注、目标国家和产品类型，以及目标功率、光通量、色温、Ra、生产数量和测算损耗加成。点击“创建项目”后进入产品方案；新项目不会复制历史档案的 BOM 或分析结果。
2. **筛选与进入项目**：在“全部项目”按项目名称、型号、来源、国家或品类筛选。点击“进入项目”选择本机研发方案；点击“查看概要”或“查看档案”核对来源和记录。
3. **编辑项目或快速重命名**：展开项目行的“管理”，选择“编辑项目”修改名称、国家、品类和备注。本机研发方案还可编辑六项目标规格。只改名称时选择“重命名”，确认后点击“保存名称”；编辑完成点击“保存修改”。
4. **核对已保存结果的适用性**：重命名或调整备注不改变已保存的 BOM 和结果。修改研发项目的国家、品类或目标规格后，旧方案、配光、光谱和核价仍保留，但标为需重新核对；重新计算和核价，再生成方案，旧报价不计入当前成本。发生版本冲突时，可“读取最新项目”后检查并保留本次输入再保存。
5. **删除与回收站恢复**：在“管理”中选择“删除项目”，核对名称后点击“移至回收站”。项目从在用列表移除，当前项目选择会自动调整。需要找回时切换“回收站”，点击“恢复项目”并确认，重新显示项目及已保存资料。
6. **查看原件与导出台账**：历史档案可展开产品版本、BOM、任务和来源，并下载原件。完成筛选后点击“导出筛选台账”下载当前列表的 CSV；回收站也可导出当前结果。历史条目的管理修改日期和原资料记录日期分别保留。
7. **复用历史型号建立新项目**：在历史设计档案中选定产品版本，点击“基于此型号新建项目”，明确新项目名称、目标国家和品类。只复用可读取的原始规格、BOM及来源关联；旧价格、库存和审批结论不继承，缺失条件在新产品定义中补齐。

可获得的结果：

- 可持续维护的本机研发项目及目标规格
- 经过名称、国家、品类与备注整理的历史档案和资料线索
- 可恢复的项目回收站与可导出台账

使用注意：

- 历史档案及目录线索只编辑台账元数据，原文件、设计版本、BOM 和历史任务不被改写；新增研发项目需要单独建立。
- 删除采用本机回收站方式，不清除已保存项目记录、原件或共享知识库；未提交的浏览器输入不作为已保存资料恢复。
- 同一母项目的产品版本不重复计为独立项目；历史核价状态不表示已量产。并发更新冲突不会覆盖他人的较新记录。

## 当前项目工作台

查看当前产品的目标、依据、已存结果与建议下一步。

软件入口：`#overview`

1. **核对当前项目**：用右上角项目选择框切换产品，核对名称、国家、品类和批量。功率、光通量、色温与 Ra 均为设计目标，不按目标值认定实测性能。
2. **按待办进入对应环节**：阅读“建议下一步”和“项目研发记录”，点击“进入”打开对应页面。待补、待核验和需更新有不同含义；仅已有保存记录不代表全部任务完成。
3. **检查结果与引用**：查看光学场景、电子物料小计、加工估算数量及当前引用依据。出现规格变化或失效引用提示时，重新核对输入和分析，再到“产品方案”重新生成。
4. **按需测算效率与价值**：展开“效率与价值测算”，填写同类任务的原流程耗时、使用后耗时（含复核）、月次数、人工费率、运行费用和一次性投入。可选假设或试点记录，补充来源后导出测算。

可获得的结果：

- 当前项目的研发记录状态及待办
- 已关联依据与已存分析摘要
- 可导出的效率与价值条件测算

使用注意：

- 效率与价值测算是浏览器本机保存的通用条件，不随项目建立归属关系。
- 工时价值不自动等于现金节省；试点应保留前后同规模任务的时间、正确性及返工记录。
- 项目名称与目标规格可在项目数据库的“管理 → 编辑项目”修改；删除当前项目后会选择剩余在用项目，没有剩余时可新增或到回收站恢复。
- “整灯核价与待确认事项”显示本项目产品基线、成本方案、冻结版本及责任人待办；未完成真实报价与路线输入时不显示已实现降本。

## 产品方案与规格

保存产品目标、型号与工程要求，明确建立只读产品版本，再生成引用当前资料与已冻结成本依据的方案草案。

软件入口：`#solution`

1. **保存产品定义**：填写目标功率 W、光通量 lm、色温 K、显色指数 Ra、生产数量和测算损耗率，点击“保存规格”。目标光效由光通量除以功率得到；保存规格不会产生实测光效。
2. **建立参考依据**：在“竞品资料”中将适用产品“加入参考”，在“资料检索与上传”按国家和产品归档资料。回到方案页面确认当前项目及已有引用。
3. **生成并核对草案**：点击“生成方案草案”或“重新生成方案”。逐项阅读研发建议、约束和待验证内容，展开详细依据，并用“阅读摘录”或“查看来源”回查原始内容。
4. **同步变化并导出**：保存新的规格、资料、光学、光谱、核价或加工结果后，按更新提示重新生成。确认当前版本后，分别下载“研发摘要”和“依据附件”；摘要用于快速沟通，附件用于追查来源与计算条件。
5. **保存型号与工程要求**：在“产品方案”填写实际型号，展开应用、电压、接线、尺寸、接口、调光、防护、PF、THD、寿命、环境与目标成本。空白表示尚未确认；保存后相关旧分析需要重新核对，不把目标当实测结果。
6. **保存产品版本基线**：导入真实工程 BOM 和相关原件后，为当前版本命名并点击“保存产品版本”。保存的需求、BOM、分析摘要及已登记原件形成只读快照；查看版本时按中文工程参数、BOM及分析状态核对，并下载对应原件。修改当前项目后另存下一版，旧版不随文件替换而变化。
7. **引用已冻结核价依据**：在整灯成本工作区冻结方案后，回到产品方案明确点击重新生成。草案引用最近的独立成本版本与原口径分组，不相加备选方案；当前工程定义已变化的基线标为历史依据，原件缺失或工程适用性仍待核验。

可获得的结果：

- 产品型号、目标规格与应用、电气、结构、性能要求
- 需求、BOM、分析状态与原件对应的只读产品版本
- 已关联市场及知识引用、已冻结核价版本的独立依据
- 知识检索与工程规则形成的研发摘要和研发依据附件

使用注意：

- 方案当前由资料检索和工程规则形成，未接入运行时大语言模型或多智能体。
- 新资料不会自动让旧草案生效；旧草案显示需更新时须主动重新生成。规则生成的 BOM 骨架需要用真实工程 BOM 替换。
- 版本保存与成本冻结是输入及计算的追溯机制，不是采购锁价或工程发布批准。

## 配光与照度

读取 IES / LDT，设置安装场景并保存直接照度预览。

软件入口：`#optical`

1. **导入对应产品的光度文件**：确认当前项目，点击“导入 IES / LDT”选择文件。导入后原件保存在本机；核对文件名、测量来源、型号及配光数据是否与该产品版本一致。
2. **无实测文件时建立概念输入**：需要研究方案方向时，设定概念光束角并点击“生成概念配光”。概念配光由目标光通量与理想分布形成，页面持续保留概念标识，后续应换为实测文件。
3. **调整并阅读场景预览**：在配光工作区调整安装、场景和观察参数，等待计算完成。核对平均、最低、最高照度与 Emin/Eavg 均匀度，并检查场景尺寸和高度单位。
4. **保存到当前项目**：确认输入和场景后点击“保存光学场景”。仅访问页面或调整预览不会保存场景；保存后回到项目工作台核对结果，重新生成方案以引用当前场景。

可获得的结果：

- 本机光度原件与对应来源标记
- 配光和直接照度场景预览
- 当前项目保存的场景及照度摘要

使用注意：

- IES 当前支持 Type C、TILT=NONE；LDT 要求有效参考光通量并进行 cd/klm 到 cd 的换算，当前快速工作区不支持非零测量倾角。
- 计算只覆盖直接光，不计反射、遮挡、日光或完整 UGR。上传文件也需核验；概念预览不能代替测量或照明应用设计。
- 目标规格改变后应重新确认原配光是否适用，重算并保存场景。

## 光谱与光质量

用实测相对 SPD 计算色度、色温、显色与 TM-30 指标。

软件入口：`#optical?view=spectral`

1. **准备实测 SPD**：进入“光学验证 → 光谱与光质量”，上传 CSV、TSV 或 XLSX，单文件最大 20MB。文件需要波长列与相对光谱列；多工作表文件填写所用工作表，列名不能识别时填写实际标题。
2. **声明单位与测量来源**：确认波长单位 nm、相对 SPD，填写测量来源或报告依据，并尽量补齐样品型号、仪器、校准与实际测量日期。未知日期留空，不用导入日期代替。勾选实测资料声明。
3. **分析并保存原件**：点击“分析并保存本机原件”。波长应严格递增、无重复和缺失，光谱值不能为负；计算区间步距不大于 5nm。至少覆盖 380–780nm，CRI 还需 360–380nm 的实测区间。
4. **阅读、切换与导出记录**：核对色度 x/y、CCT、Duv、CRI 与 TM-30，以及缺失指标的原因。可在“本项目光谱记录”切换历史记录、下载原件和导出当前分析；产品版本变化后重新确认适用性。

可获得的结果：

- 保留测量来源及文件身份的本机光谱记录
- 相对 SPD 曲线、色度与适用的显色计算
- 光谱分析导出及实测原件

使用注意：

- IES 描述空间配光，SPD 描述波长分布，二者不能互相反推。不能从目标 CCT 或 Ra 构造实测光谱。
- 相对 SPD 不计算实测流明、光效或电气安全；计算结果与测量质量、型号对应关系仍需复核。
- 线上版原件和分析记录保存到服务器工作空间，成员共享；本机版仍保存在当前电脑。

## 电子 BOM 与报价

导入工程物料表，查询供应候选并人工确认价格口径。

软件入口：`#bom`

1. **导入真实工程 BOM**：点击“导入 BOM”或拖入 XLSX、XLSM、CSV、TSV，最大 20MB。表头至少含数量或位号，以及规格、制造商料号或立创编号之一；建议同时提供封装、品牌和单台用量。导入会保存当前项目的 BOM。
2. **配置嘉立创 SMT 查询**：展开“应用凭据与价格口径”，填写开放平台 App ID、Access Key、Secret Key，点击“保存本机配置”。应用需要 SMT 查询权限与正确的出口 IP 白名单。使用测试料号点击“测试连接”，按诊断核对权限、配置及网络；已配字段留空会保留原值。
3. **核对物料与计价口径**：选择“嘉立创 SMT · 真实接口”，逐行填写 C 编号或精确原厂型号，设置批量与损耗率，点击“查询并核价”。在供应物料查询区也可单独查询后填入 BOM 行。核对每个候选的型号、品牌、封装、库存和参数，并人工选择；修改选择后再核价。
4. **确认价格并查缺项**：核对接口单价确为 CNY/个后，在配置区确认价格口径并保存，再执行核价。检查需求数量、采购参考量、价格阶梯、MOQ 及未决原因。未确认、无价、冲突或外部询价行保持待补，不计作已定价金额。
5. **保存结果并导出**：核价请求完成后结果按当前项目保存，点击“导出核价 CSV”保留来源、观测时间和未定价原因。演示料库需单独选择，其候选与金额只供流程练习，不能作为真实采购依据。

可获得的结果：

- 当前项目工程 BOM 与供应查询编号
- 人工确认的候选、库存与价格证据
- 已定价电子物料参考小计及核价 CSV

使用注意：

- SMT 接口与商城零售、海外 LCSC 的应用凭据和价格范围不同。密钥仅保存在本机配置，不在页面回显。
- 一次最多查询 30 行。接口成功不表示候选可电气替代；驱动隔离、调光、LED 分档、热及可靠性要求需规格书核对。
- 需求量按单台用量×数量×（1+损耗率）向上取整；未知 MOQ、税费或包装条件保留未决。电子小计不含完整结构、PCB、加工、测试、包装和税运费用。
- 在项目管理中修改国家、品类或目标规格后，已保存报价属于旧版本参考；重新核对 BOM 并核价前不作为当前成本。
- 线上版的供应接口凭据、连接测试和价格口径确认由管理员维护；获批成员可查询物料并核价。

## 工艺加工测算与 MVA

按工厂节拍、良率与人工设备能源费率估算单工序加工增值成本。

软件入口：`#manufacturing`

1. **先核对工艺原理**：从“照明知识库 → 制造工艺知识”或“查看工艺知识”选择工艺，阅读成形原理、适用部件、关键条件、质量风险和原始来源。需要补充工艺卡或报价时，使用“上传工艺资料”。
2. **选择工序与产能口径**：进入“成本核算 → 工艺加工测算”，确认当前项目，选择注塑、挤出、压铸等工艺和对应计算模式。填写本批目标良品数、每灯用件数；周期模式填完整周期和有效穴数，连续模式填毛产速与单件净重。
3. **填写真实费用与良率**：填写效率、良率、人工、纯机时、电能、间接费、耗材与换型条件。效率不含良率；实测节拍已包含的损失不再重复扣减。选择综合小时包干费时，明确已含费用，避免再次叠加。未发生的必填费用明确填 0。
4. **分别处理材料、模具与委外**：独立模具价值按寿命良品件分摊，原料与外售废料可按已确认单价另计；内部回用不能再抵扣外售收入。委外良品计件模式单列服务费，不叠加内部人工与能耗。填写费率日期、来源及税口径。
5. **计算并保存当前工序**：点击“计算该工序”，核对每良品件 MVA、每灯该工序分摊和费用明细。填写估算名称后点击“保存本项目估算”。修改输入后先重新计算；历史记录可“回填”后重算保存。示例注塑条件只回填草稿，正式使用需替换工厂条件。

可获得的结果：

- 单工序产能与费用构成
- 人工、设备、能源等加工增值成本 MVA（元/良品件）
- 当前项目的工序估算记录

使用注意：

- MVA 采用加工增值成本口径；原料、独立模具摊销及委外服务另列，不自动写入 BOM。
- 单工序估算不能直接相加当作整灯 MVA：完整工艺路线需核对数量转换、累计良率和下游报废对前序费用的影响。
- 含税与未税费率不能直接比较；本版保留填写口径，不自动剥离税额。

## 材料行情与日 K

观察金属、树脂、能源与辅材基准的变化，研究材料成本敏感性。

软件入口：`#materials?view=quotes`

1. **查看本机行情与来源时点**：进入“材料与物流 → 行情趋势”，按金属、塑料、工程塑料或能源与辅材筛选。先看行情类型、计价单位、源时点及本机获取时间，判断该数值的适用范围。
2. **按需更新公开行情**：点击“更新公开行情”，或在行情页勾选“每 60 秒自动获取”。更新取决于公开源的可用性和发布频率；查看成功、缓存或失败标识，失败时旧值保留原来的源时点。
3. **阅读真实日 K**：点击材料行的“查看 K 线”，选择 60、120 或 250 根窗口、日 K 或收盘线，按需启用 MA5/MA20；可缩放、重置和“更新日 K”。阅读开高低收时同时核对来源、周期和单位。
4. **检查记录与费用影响**：点击“记录与口径”或“日 K 来源与证据”回查历史观测。需要估算重量敏感性时选“用于测算”，填写单灯净用量 g、损耗加成和数量，查看该基准价下的参考影响。

可获得的结果：

- 本机保存的公开行情与源时点
- 支持材料的真实历史日 K、收盘线及均线
- 手工重量条件下的材料成本敏感性

使用注意：

- 连续期货反映上游价格趋势，不能代替具体牌号、颜色、改性版本、地区和税运条件的现货采购报价。
- 报价与日 K 分别获取，不从单次观测构造开高低收；缺失交易记录不会补造。工程塑料现货是否可自动读取以来源授权和页面状态为准。
- 单位按材料显示，银可能为元/kg、原油为元/桶；没有可确认质量换算口径时不做单灯重量计价。敏感性结果不自动写入 BOM。

## 公路距离、油价与物流费用

比较出发城市到四个港区的公路参考距离，测算油价对运输费用的影响。

软件入口：`#materials?view=logistics`

1. **选择城市和港区**：在“材料与物流”点击“物流与运费”，选择横店、瑞金或已存参考点，以及宁波北仑、厦门海沧、深圳盐田、广州南沙。点击矩阵中的里程将路线选入测算。
2. **核对或更新公路路线**：点击“查询路线”或“更新所选城市的 4 条路线”，检查里程、获取时间和参考点来源。真实厂门至货运闸口的公路里程已确认时，可在测算区填写覆盖值。
3. **补充其他城市参考点**：展开“增加其他出发城市的参考点”，填写名称、纬度、经度并“保存本机参考点”。保存只建档；主动规划路线时，坐标才发给公开路线服务。
4. **查看国内油价调幅**：点击“更新官方调价”，查看全国汽油、柴油每吨调整额及公告、生效时间。运输测算另行填写真实地区、油品、价格日期与柴油元/升，不用全国调幅代替当地零售价。
5. **测算已填运输费用**：选择单程或往返，填写车辆百公里油耗、实际升价、本车装载灯具数量、路桥费和其他已核算费用。输入柴油升价变化可看燃油费用敏感性；结果随输入更新，无自动写入 BOM 的动作。

可获得的结果：

- 城市参考点到四港区的公路距离与来源证据
- 官方全国成品油调价观察
- 燃油费用、已填费用合计及元/台分摊

使用注意：

- 公路距离来自普通驾车规划，不是承运商报价或已核验货车路线；限高、限重、收费、装卸和港区等待需另核。
- 往返只将同一里程乘二，空返、返程接货或不同载重油耗需另算。费用合计仅覆盖已填写项，不代表最终运费结算。
- 全国元/吨价格调整量不能直接换算成地区柴油元/升，也不能将油价涨幅直接乘全部运费。

## 资料检索与上传

原件归档一次，按国家与产品检索摘录，并用于研发方案引用。

软件入口：`#knowledge?view=documents`

1. **设置资料归属**：进入“照明知识库 → 资料检索与上传”，选择归属国家与适用产品类型。通用资料可选全部国家或通用工程；具体型号与版本建议放在文件名和原文中，便于检索核对。
2. **选择识别方式并上传**：支持 PDF、DOCX、XLSX、CSV、TSV、MD、TXT、JSON 和 PNG/JPG/JPEG，单文件最大 20MB。“自动”按资料情况选择文本或本机 OCR；“智能版面”保留表格与页码，最多 50 页；已有清晰文字可用“快速”。点击或拖入原件提交。
3. **核对提取与定位**：上传成功后按关键词、国家、产品和“已上传资料 / 全部知识索引”检索。点击“阅读内容”，核对摘录、页码、表格和关键单位，必要时下载原件逐项检查。识别失败时检查文件可读性、大小、页数或更换识别方式。
4. **使资料进入当前方案**：共享资料不会在项目切换时自动成为已验证依据。确认当前项目的国家、产品和目标，再回到“产品方案”重新生成，核对实际引用内容及其适用性。
5. **管理原件与失效引用**：展开“该国家全部原件 · 下载与管理”，下载或删除原件。删除会移除检索索引，并使相关引用标记失效；补入替代资料后重新生成方案。删除前确认仍需保留的原件已有备份。

可获得的结果：

- 当前工作空间保存的原件与可定位文本、表格摘录
- 按国家和产品检索的资料索引
- 方案中可追溯的知识引用

使用注意：

- 上传内容作为待核验资料，不执行其中的指令。OCR 与表格识别可能误读，型号、数值、单位和页码必须复核。
- 本机版面识别使用已准备的模型及 macOS OCR；线上 Linux 包不带模型和 Apple Vision OCR，初期优先用快速文本提取，扫描件识别需补充服务器兼容的 OCR。资料解析不需要将原件发往外部模型服务。
- 资料上传或删除后旧方案需要重新生成，上传报告本身不代表产品满足标准。

## 国家认证与进口准入

按目标国家、产品与要求维度整理准入路径、技术要求和出货证据。

软件入口：`#knowledge`

1. **按国家与产品初筛**：进入“照明知识库 → 国家准入标准”，选择目标国家和产品形态：LED 灯泡、双端替换灯管、室内灯具、投光灯、路灯或独立驱动等。智能无线产品勾选“包含智能无线功能”。
2. **选择要求维度**：分别查看认证与进口准入、电气与光生物安全、性能与能效、EMC、环保与回收及无线通信。也可搜索 TISI、CE 或标准编号，缩小需要核对的条目。
3. **核对范围、版本与时间**：展开条目，阅读适用范围、强制或条件状态、标准、技术要求和实施过渡日期。按实际灯头、电压、功率、用途、销售形式及出货时间确认型号是否落入范围；通过官方来源检查现行状态。
4. **建立出货资料清单**：阅读“认证 / 进口资料”“出货前确认”及资料缺口。点击“补充规格与认证资料”，按国家和产品上传证书、报告与规格，继续核对型号覆盖、持证主体、版本和有效期。
5. **导出当前准入参考**：点击“导出当前清单”，保留筛选条件、适用范围、官方来源和待核验事项。将清单作为产品与出货核查输入，再由合规人员和认证机构确认具体办理路径。

可获得的结果：

- 按国家、产品、维度筛选的准入参考条目
- 技术核对、认证进口资料与缺口清单
- 可导出的当前准入清单

使用注意：

- 例如泰国 TISI 的适用性需按具体产品范围和当前强制目录核对，不能理解为全部照明产品使用同一种证书。
- IEC 标准与 CB 报告是技术或认可依据，是否强制、采用版本和国家差异仍需按当地制度确认。
- 无匹配条目只表示本库覆盖不足；检索、上传证书或导出清单均不代表已取得进口准入。

## 保存、备份与分享范围

6. **导出作品集与只读浏览页**：维护人员在实际安装目录运行 scripts/export_github_pages.py，再运行 scripts/package_github_pages.py，生成个人作品集首页和 LumiPilot 子目录的静态网页包。只读页沿用现有界面与已保存公开记录，支持项目查看、市场与国家知识筛选、已存行情和使用说明；不复制运行数据库，不新建模拟项目。具体发布步骤见 docs/github-pages-publication.md，只有 GitHub 文件提交及 Pages 构建通过后才能发送网站链接。

可获得的结果：

- 清晰的项目归属与共享资料范围

## 邮箱登录与访问管理

线上版使用邮箱验证码和管理员审批；本机可准备邮件配置，部署包提供香港服务器指南、私有配置向导和上线前检查。

软件入口：`#access`

1. **本机准备邮件服务**：从左侧“线上部署设置”填写 SMTP 服务器、端口、TLS 方式、用户名、密码或授权码、发件人邮箱及名称，然后保存。本机版仍直接使用；保存不会发送邮件或开放公网。
2. **准备线上部署**：首次购买香港服务器先阅读部署包中的 docs/hongkong-deployment.md，准备服务器、实际域名和发信服务。在服务器运行 python3 scripts/configure_online.py，交互填写域名与 SMTP，自动创建两项独立随机密钥和私有 .env.online；已有配置不会被覆盖。首位管理员为 [邮箱未公开]。本机页面保存的邮件配置不会自动复制到服务器。
3. **检查与启动服务器**：在解压后的程序目录执行 python3 scripts/deploy_online.py check；缺少实际域名、独立代理密钥或完整 SMTP 时不能启动。准备齐全后，在 Linux 服务器执行 sudo python3 scripts/deploy_online.py start，再通过正式 HTTPS 地址验收管理员验证码和用户审批。检查不发信、不创建业务库，也不核验 DNS、证书或大陆访问效果。已有配置请编辑原文件并保留密钥，命令细节见部署指南。
4. **验证邮箱并申请访问**：打开线上地址的 /login 登录页，输入邮箱并发送验证码，再填写邮件中的六位验证码。验证码有效期 10 分钟，重发间隔 60 秒，错误尝试次数有限。首次普通用户显示待审批；首次管理员完成邮箱验证后建立管理员账户。
5. **审批与进入工作台**：管理员在“访问管理”查看待审批用户，点击“批准”或“拒绝”并确认。用户在等待页点击“检查审批结果”；获批后进入共享工作台，无需再次验证仍有效的登录会话。被拒绝的用户只可查看申请状态。
6. **停用与恢复成员**：管理员可筛选已批准成员并“停用”，现有会话即时失效。被拒绝或停用的成员可重新批准；停用后恢复访问需要重新登录。账户权限变化不删除已保存项目或资料，首位管理员不能通过此页面停用。
7. **邮件配置与退出**：管理员可在“访问管理”更新发信服务。密码不回显，留空保留已有值；环境变量优先于页面配置。点击“退出登录”撤销当前会话；登录会话最长 8 小时，到期需重新验证邮箱。

## 整灯核价、工艺路线与降本比较

按产品基线形成可追溯的内部成本方案，分别核对生产耗用、采购现金、MVA、模具、委外、包装与物流。

软件入口：`#cost`

1. **选择真实产品基线并建立草稿**：在成本核算的“成本总览”选择已保存的产品版本，填写方案名称、最终良品灯数和核价日期。首轮建议用真实 A 灯泡与 T8 各一个；软件不会自动填入采购价、工厂费率或真实试点成果。可读取基线 BOM 作编辑起点；规则生成的演示 BOM 不能形成真实工程核价结论。
2. **导入与确认采购报价**：在“BOM 与采购报价”下载空白模板，上传 XLSX、CSV 或 TSV（最大20MB、5000行）。按原表列映射料号、供应商、单价、单位、MOQ、订购倍数、日期、有效期与来源，重新预览后逐行选择并人工确认入库。重复列与错误数据需先处理；公式不执行，应先转换为明确数值。报价保留原件与哈希，不把历史行情当采购报价。
3. **绑定报价与自制或外购方式**：每行填写精确部件图号/料号、每灯用量及所选报价。外购成品使用件或套价，不能再计相同部件的自制加工；自制部件另填原材料牌号、净重和每投入件投料重，绑定千克或吨价。成品图号与粒子牌号分别核对。独立模具整套价格须通过路线寿命摊销，不按单灯普通 BOM 数量直接计入。
4. **建立顺序工艺路线**：在“工艺路线与 MVA”新建路线，为自制部件选定顺序工序，并建立最终装配、测试或包装工序。新增最终装配默认为“装配、测试与老化”；改工艺时同步默认名称，已自定义名称保留。可从已保存单工序估算复制条件，但需核对工艺、节拍/产速、穴数、可用率与速度效率、良率、费率来源及日期。空费率保留未知，明确不计的费用填0；包干费用与已包含的人工、能源、间接费不得重复添加。
5. **确认投入节点与数量口径**：BOM行可在装配起点、具体装配工序或最终良品阶段投入；包装默认在最终良品阶段投入，仍需按实际路线核对。系统反推各工序需求，后段报废会携带前段成本，多穴按整循环取整；连续工序按实际口径计量。已选路线良率后不另加项目全局损耗。首版不处理返工循环、联产品及跨型号共享资源分摊。
6. **核对模具、计费范围与物流**：路线中的独立模具填写摊销总额与寿命预期良品数量，已包含或明确不计填0。分别确认 BOM、制造、包装、物流的范围，不适用项填写原因。在总览保存承运商整批总报价或每趟分项物流估算，两种方式互斥。整批报价直接计入整批预算；分项估算按最终良品灯数除以每趟载量向上取整车次。具体厂门、港区、运输段、载量、费用来源与有效期需明确，分项费用使用同一币种。相同运输段已含入供应报价时不再追加。
7. **保存计算并检查未决项**：先保存草稿，再计算。每灯生产耗用与内部 MVA 分开显示；同一选定报价的多行需求合并一次 MOQ、订购倍数与阶梯价，采购现金和剩余库存在采购分组中单列。不同报价版本不自动合并。保留原税口径，不剥税、补税或换汇；币种、税运口径不一致时只给分组小计，不输出统一总成本。
8. **分派确认事项并冻结**：对缺报价、过期、参数不足、范围未确认或工程适用性待核对的事项填写责任人、期限、证据与意见。审阅记录不直接填补金额或消除计算缺项，补齐输入后需重新计算；旧计算的审阅标为待重新核对。冻结保存当时计算与来源，部分数据也可作为明确的历史参考冻结；修改需基于旧版本新建草稿。 导出的待确认事项附带当前计算对应的责任人、期限和核对依据；计算阻断项不会因填写“已完成”而被消除。
9. **比较降本候选并导出**：在“方案比较”选择两个冻结方案。同产品基线、数量、核价日期及明确原币种税运口径、且无计费阻断缺项时显示差额；条件不同只列变化与原因。替代材料、减重、换供应或工艺仍需光学、热、阻燃、可靠性和目标国准入核对。总览可下载成本 Excel 与版本依据 ZIP，来源更新不改写旧冻结金额。
10. **回填实际结果**：冻结预算后录入采购结算、实际耗用、加工或物流金额、日期、单位和原始依据。采购支出与耗用分开；明确勾选记录覆盖所选范围完整实绩后才按一致口径核对偏差。单行实绩选定对应 BOM 行，缺项或不同范围不会被当成整批节省。

可获得的结果：

- 绑定产品基线、订单数量与核价日期的成本版本
- 可定位报价原件、工艺输入与计算条件
- 生产耗用、采购现金、超买库存、内部 MVA 及独立费用分组
- 同口径降本比较、工程待确认事项与实绩偏差
- 中文表头的 Excel 成本、采购库存、工艺与物流明细，以及只读版本依据附件

使用注意：

- 成本完整性只表示明确声明的计费范围与输入具备；不表示工厂保证、采购锁价、样机达标或认证通过。
- MVA仅含内部人工、设备、能耗、耗材、换型与制造间接费；材料、委外、独立模具及物流分别列示。
- 公共期货、油价和参考公路距离继续用于趋势及敏感性，不自动替代具体牌号采购价、柴油升价或承运商报价。
- 未知值不是零；税运和币种不一致不自动合计，源价格和日期不因读取或冻结变新。
- 整套工艺与成本软件功能已建立，真实两款试点仍需完整工程 BOM、供应报价、工艺卡、费率、良率及结算依据。未录入前保留资料待补状态。
- 本机与获批线上成员使用同一业务逻辑；操作记录操作者，输入冲突拒绝覆盖，修改已冻结方案须新建版本。
