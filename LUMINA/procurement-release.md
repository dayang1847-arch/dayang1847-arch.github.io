# LUMINA 独立采购方案页

发布版本：1.2.39。

- 作品集首页 LUMINA 卡片新增“采购与节能对比”入口。
- 公开照明演示导航新增“采购方案”，带入当前浏览器方案的数量与产品版本。
- 独立页面：`purchase.html`。比较标准采购、分阶段升级、全面高光效、分时控制四种组合。
- 使用规则生成的 MOQ 阶梯演示价；支持初购预算、年电费、长期成本、简单回本期和 CSV/HTML 导出。
- 比较条件单独保存，兼容已有公开版方案格式。未上传本机方案、真实报价库、目录文件或任何凭据。
- 本机版 1.2.39 已把采购功能移出电源与布线页。

验证：20 项采购/布线测试通过，TypeScript 检查通过；公开页浏览器验证了独立入口、当前方案数量、刷新后保留比较条件和场景返回入口。公开 JavaScript 语法与中英文作品集文案键检查通过。GitHub Pages 的部署完成情况以工作流及线上页面实际结果为准。
