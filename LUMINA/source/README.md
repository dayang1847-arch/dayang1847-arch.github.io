# LUMINA 照明演示系统

面向展厅演示的本地应用。内含办公展厅与户外园区、灯具产品仓库、STEP / IGES / GLB 导入、IES 分析、电影式镜头巡游及 DALI / D4i 设备模拟。

## 打开应用

macOS 双击 **启动照明演示系统.command**；Windows 双击 **启动照明演示系统.bat**。本机地址为 http://127.0.0.1:3040/。运行窗口保留；关闭窗口将停止服务。

需要 Node.js 22.13 或更新版本。项目已安装运行资源；首次在另一台电脑安装需要联网，之后支持断网运行。也可在本目录执行：

```sh
npm ci
npm run build
npm start
```

所有产品、方案、原始文件和转换缓存保存于 `data/`。升级代码时保留此目录。可通过 `LIGHTING_DATA_DIR` 指定独立的数据目录，`LIGHTING_PORT` 指定本机端口。服务只监听本机，不提供云端账号或局域网共享。

## 使用

完整操作说明见 [使用说明](docs/使用说明.md)，软件右上角的帮助入口也提供主要步骤。

- 选择已有灯具后，从产品仓库点击另一款产品进行替换。
- 排布编辑显示安装位和移动 / 旋转轴。右侧可修改坐标、高度、朝向、色温和光输出。
- 场景右上角的灯具列表可逐盏选择，也可直接打开该灯具的 IES 文件。
- 产品卡片和灯具参数面板均提供“查看 IES”；支持原文、光强矩阵和原始文件下载。
- 照明预设和分组光输出控制改变场景参数；镜头巡游提供自动观察，手动旋转会暂停巡游。
- IES 分析支持工作面、地面和垂直面；报告可在页内预览、打印或另存为 PDF，并下载完整 HTML。
- 设备演示先自动绑定模拟设备，再应用场景；可演示离线、拒绝命令、超时和恢复。
- 设备演示的“技术后台”显示控制架构、网关与寻址、确认状态、实际操作的持久命令日志以及本地 API；所有总线与 D4i 数据均注明模拟来源。
- 修改自动保存，保存按钮同时记录视角；方案菜单可另存、导出和导入包含模型及 IES 的 ZIP 包。

## 支持与边界

IES：LM-63、Type C、TILT=NONE。计算为人工照明直接光，未计入反射、遮挡、日光和 UGR。渲染包含视觉阴影和环境光，效果图像素不等于照度读数。内置样品与其 IES 明确标注为生成的演示数据。

CAD：STEP / STP、IGES / IGS，在独立进程中转换为米制网格，保留装配与颜色。单模型 100 MB，转换超时 120 秒；简化转换可重试。GLB 支持 glTF 2.0，Draco 解码资源在本机。模型校准决定安装原点、发光中心与光学方向。产品文件按版本保护，编辑资料创建新版本，已有方案继续引用原版本。

硬件：目前提供模拟网关、64 台模拟设备及适配接口。D4i 灯具资料、能耗和诊断为模拟数据。实际控制器需依据品牌型号与接口资料实现适配器，未声明任何未经联调的真实硬件兼容性。

## 开发与验证

```sh
npm run dev
npm run check
npm test
npm run build
```

React + TypeScript + Vite + Three.js WebGPURenderer，自动回退 WebGL 2。兼容模式可用 `?webgl`。CAD 使用未修改的 `occt-import-js`；数据保存采用原子写入，导入包校验文件摘要并重建独立编号。

本地 API 与设备适配说明见 [接口说明](docs/接口说明.md)。自动测试覆盖光度计算、CAD 单位与装配、保存恢复、方案迁移、设备异常和 IES 文件保真。

## GitHub Pages 在线演示

`npm run build:public` 生成 `dist-public/`，可直接放入个人网站的子目录。网页版使用内置演示产品，支持场景、排布、IES、报告、模拟设备与浏览器保存；浏览器中的方案 ZIP 可导入完整本地版。自有模型 / CAD 导入、原始资产库和实体网关适配使用本地版，线上不提供服务器接口或上传服务。
