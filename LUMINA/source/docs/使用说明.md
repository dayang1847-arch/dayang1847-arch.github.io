# 照明演示系统使用说明

## 1. 场景与视角

在“室内 / 户外”之间切换。室内为办公展厅，含展示区、会议区与休憩区；户外为园区，含道路、步道与景观区。户外可选择白天、黄昏、夜间。

拖动鼠标旋转视角，滚轮拉近或拉远。底部“镜头巡游”在预设镜头之间平滑切换；手动操作会暂停巡游。“恢复全景视角”返回初始观察位置。“全屏演示”收起仓库与参数面板。画质可选流畅、均衡、精致；复杂结构模型建议流畅档位。

## 2. 灯具搭配

点击三维场景的灯具或右上角“灯具”列表选择一盏灯，再从左侧仓库选产品进行替换。分类和搜索用于筛选产品，仓库只显示适用于当前场景的产品。

未选中场景灯具时，点击产品会进入排布编辑。安装位以标记显示，点击标记放置灯具；已有灯具的安装位可直接替换。右侧坐标 X / Z 为地面位置，Y 为安装高度，单位为米。旋转以 XYZ 欧拉角表示，单位为度。

“排布编辑”中可以拖动移动轴或旋转环；释放鼠标后更新分析。右侧也可直接输入坐标与角度。“复制”生成新灯具，“删除”移除选中的灯具。“分组排列间距”输入数值后按回车，将同组灯具沿其主要排列方向重新排列。

## 3. 调光、色温和预设

右侧控制选中灯具的开关、光输出比例与色温。固定色温产品的色温控制禁用。光输出按 IES 光强的线性比例计算，不代表具体 DALI 控制器的原始码值。

底部可以选择全部灯具或指定分组，统一调整光输出；照明预设可快速切换。加号保存当前灯具的亮度与色温为新预设。同一场景切换方案时保留当前观察视角，方便比较。

## 4. 查看每盏灯的 IES

有三个入口：场景“灯具”列表中的 IES 图标、选中灯具后的“查看 IES 文件”、产品仓库卡片的“查看 IES”。所查看文件始终对应灯具引用的产品版本。

“原始文件”显示完整 LM-63 原文。“光强矩阵”显示已应用光强倍率的 cd 值，垂直角按页显示，最多显示前 16 个 C 平面。完整原始矩阵可查看原文或下载。上传的 IES 下载保留原文件字节和文件名；内置样品下载为与样品配光一致的生成 IES，并带有 DEMO 标识。调光、位置和旋转不会改写产品的 IES 文件。

## 5. IES 照度分析

分析模式包含水平工作面、地面和垂直面。水平面以 X / Z 为坐标，垂直面以 X / Y 为坐标，朝向 +Z；垂直面位置可用 Z 输入框调整。设置面宽、深度 / 高度、中心高度与维护系数；默认维护系数为 0.8。

平均、最小、最大照度与均匀度根据计算网格统计；均匀度为最低照度 / 平均照度，全关时为 0。指针在热图上移动可读取附近网格点的照度。等照度线为当前最大值的 20%、40%、60%、80%。参数变化后旧结果立即失效，后台重新计算。

仅计算人工照明的直接光，未包含墙面反射、遮挡、日光和 UGR。3D 展示的环境光与视觉阴影不计入分析。报告包含计算条件、照度图、场景截图与灯具清单；在页内报告预览中点击打印即可选择另存为 PDF，也可下载包含图片和清单的完整 HTML 报告。

## 6. 新增自有产品

1. 点击“新增产品”，填写名称、型号、类别、额定功率、色温与适用场景。IES 未包含的资料需要自行填写。
2. 上传 STEP / STP、IGES / IGS 或 GLB，再上传对应 IES。STEP / IGES 在本机转换为米制网格；显示排队、转换与保存阶段，可取消或简化重试。
3. 在预览中校准。CAD 转换后通常保持缩放 1；GLB 单位依文件而定。安装原点使用转换模型的原始坐标；模型姿态作用于外观。发光中心使用校准后的灯具局部坐标，默认光学方向为向下 −Y，C0 默认朝局部 +X，可调整。
4. 点击零件可选择发光面并将发光中心设为点击位置；也可通过坐标输入修正，或选择多个发光零件。每个产品使用一个 IES 光学发光中心。
5. 确认尺寸、原点、发光中心、方向与材质，勾选校准确认后保存入库。未完成的资料可以保存草稿；草稿不参与排布与分析。

编辑自有产品会复制资产并新增产品版本。旧方案引用的旧版本不会发生变化。部分复杂 CAD 可能需要移除不影响外观的内部结构件后再导入。

## 7. 设备演示

设备页面始终标明模拟。先自动绑定当前场景的灯具，再点击“应用到设备”；控制结果需要反馈确认，失败或超时保持旧状态。可手动选择设备绑定，并模拟单设备离线、网关断开和命令拒绝。

D4i 页显示支持该能力的模拟设备的灯具资料、功率、累计能耗、时长与诊断信息。所有数据为模拟。真实 DALI / D4i 网关需要依据设备接口资料开发与联调适配器。

“技术后台”展示模块细节：控制架构、连接方式、运行环境、总线 / 短地址、驱动能力、绑定信息及确认值。“命令日志”可逐条查看逻辑请求、响应、延迟和失败原因；“接口与数据”展示本地 API 和 D4i 字段结构。最近 200 条操作保存在本机，重启后保留。当前没有实体网关，因此未提供真实 DALI 总线报文。

## 8. 保存与迁移

编辑后自动保存到本机。保存按钮同时记录当前镜头。方案菜单中可另存为新方案，或打开已有方案。导出当前方案或完整仓库会包含产品版本、原始模型、转换缓存、IES 及缩略图；导入建立独立副本。

数据目录为项目中的 `data/`，升级时保留此目录。建议定期导出完整仓库作为备份。软件运行无需联网；复制到新电脑后首次安装依赖需要联网。

快捷键：⌘ / Ctrl + S 保存，Delete 删除选中灯具，Esc 退出编辑、巡游或当前文件查看。
