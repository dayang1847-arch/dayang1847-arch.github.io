# 本地接口与扩展

服务只监听 `127.0.0.1:3040`，浏览器与服务在同一电脑。类型定义在 `shared/types.ts`。

| 接口 | 用途 |
|---|---|
| GET /api/state | 产品所有版本、方案、转换任务和设备状态 |
| POST /api/products | 新增产品或新增现有产品版本 |
| GET /api/products/:id/ies?version=N | 对应版本的文件名、原文与来源 |
| GET /api/products/:id/ies?version=N&download=1 | 下载原始字节，演示样品生成 LM-63 文件 |
| POST /api/plans | 验证并原子保存方案 |
| POST /api/uploads | multipart 模型上传；返回资产编号与 CAD 任务 |
| POST /api/assets/:id/ies | 为尚未发布的资产保存配光 |
| POST /api/assets/:id/clone | 编辑产品前复制资产，保护已发布版本 |
| POST /api/assets/:id/thumbnail | 保存 PNG 预览 |
| GET /api/assets/:id/:filename | 读取模型、配光、缓存和缩略图 |
| GET /api/jobs | 当前进程中的任务队列 |
| POST /api/jobs/:id/cancel 或 retry | 取消或简化重试转换 |
| GET /api/export?planId=... | 导出单个方案；省略参数导出完整仓库 |
| POST /api/import | 验证 SHA-256 后导入 ZIP，创建独立编号 |
| GET /api/devices | 模拟设备及绑定状态 |
| GET /api/control/diagnostics | 适配器、真实本地运行状态、模拟寻址能力及持久命令日志 |
| POST /api/devices/discover | 发现模拟设备 |
| POST /api/devices/bind 或 auto-bind | 手动或按方案绑定 |
| POST /api/devices/apply | 应用方案到已绑定设备，返回确认状态 |
| POST /api/devices/configure | 连接状态、离线与异常响应模拟 |
| WebSocket /api/events | 任务阶段、设备反馈、目录变更事件 |

所有失败接口返回 `{ "error": "具体原因" }` 与非 2xx 状态码。模拟数据使用 `simulated: true` 标识。命令与反馈分离，修改前端方案不会自动向硬件发送命令。

## 技术后台

设备演示中的“技术后台”展示控制服务 → 适配器 → 模拟总线的关系，以及连接状态、地址、调光 / 色温能力、当前确认值与绑定灯具。Node 版本、运行时间、进程内存和保存路径来自实际本地服务。

命令日志保留最近 200 条，存于 `data/control-log.json`，每条包含请求编号、操作名、请求时间、逻辑 payload、响应、耗时和失败原因。`wireFrame: null` 表示没有真实实体网关报文。日志状态从 pending 转为 confirmed 或 failed；重启前未确认的请求标为 failed，不自动补发。技术后台每 2 秒刷新，并提供本地 API 目录和 D4i 数据结构。

## 实际设备适配

`server/devices.ts` 的 `LightingAdapter` 包含 connect、disconnect、discover、capabilities、setLevel、setCCT、applyScene、status。实际适配器将 0–100% 的逻辑光输出转换为网关需要的调光码值，按设备能力限制色温，并在状态反馈后确认命令。

需要网关型号、接口说明、寻址方法、总线拓扑、设备能力、反馈规则与现场联调条件。D4i 作为 DALI 的灯具、能耗和诊断数据能力处理。此版本不包含任何具体厂商真实网关驱动。

## 文件与版本

元数据版本为 schemaVersion 1。产品引用由 id + version 构成，场景灯具实例持有固定引用。产品资产在保存后不可通过上传接口改写，编辑先复制。场景修改递增 revision，分析结果绑定对应 revision，过期任务终止。

导入校验先于持久写入，资产重编号，产品和灯具编号重新映射；导入日志支持中断恢复。运行期间取消的 CAD 转换可在同一进程重试，原始源文件保留。服务重启后再次打开草稿，可以重新上传源文件启动转换。
