# LUMINA 在线演示

此网页仅供交互演示。可以体验两个三维场景、灯具搭配与排布、逐灯 IES 查看、直接光照度分析、报告预览及模拟智能控制后台。

使用内置演示样品，方案与模拟记录保存于当前浏览器。未连接服务器或实体网关；D4i 资料、能耗与诊断为模拟数据。照度分析未计入反射、遮挡、日光和 UGR。

支持 STEP / IGES / GLB 模型与 IES 导入；CAD 在独立浏览器后台任务中转换。模型保存在此浏览器的产品库，方案、产品与原始资产可打包导出并导入为独立副本。报告可预览、打印保存 PDF 或下载 HTML。

不提供应用安装包或完整应用源码包。清理浏览器数据会删除本机演示资料，请通过方案菜单备份自己的产品和搭配。
