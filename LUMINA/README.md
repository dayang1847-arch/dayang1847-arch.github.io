# LUMINA 照明演示系统

[在线体验](./) · [下载完整本地版](./LUMINA-local.zip) · [源码与启动说明](./source/README.md)

在线版可体验办公展厅与户外园区、选灯排布、调光与色温、镜头巡游、逐灯 IES 文件、直接光照度分析、报告以及模拟 DALI / D4i 控制和技术后台。方案与命令日志保存于访问者的浏览器，不上传到服务器。

内置灯具和 IES 均为演示样品。未连接实体网关；D4i 资料、能耗与诊断为模拟数据。照度分析未计入反射、遮挡、日光和 UGR。

完整本地版提供 STEP / IGES / GLB 与 IES 产品导入、独立转换进程、资产库与设备适配接口。下载并解压后安装 Node.js 22.13 或更新版本，运行 npm ci、npm run build，双击启动入口。首次安装需联网，之后支持断网演示。

公开发布仅包含内置样品、应用源码及运行资源，未包含本机 data/、账号或客户文件。第三方许可位于 licenses/ 及 source/docs/licenses/。
